# HASAN oil — сайт-каталог

Одностраничная витрина натуральных масел HASAN oil (Грозный, Instagram [@hasan.oil](https://instagram.com/hasan.oil)).
Заказа на сайте нет — только каталог с ценами и связь через WhatsApp.

Статический сайт без фреймворков и бэкенда: открывается на GitHub Pages по адресу
`https://<username>.github.io/hasan-oil/`. Все пути относительные.

## Структура

```
index.html          — разметка страницы (шапка, преимущества, доставка, о нас, подвал)
style.css           — стили (mobile-first)
script.js           — каталог: табы, поиск, карточки, модальное окно
products.json       — ВСЕ товары и цены (редактировать здесь)
assets/             — логотипы, favicon, картинка для превью ссылки (og-image.jpg)
photos/             — фото товаров в WebP (то, что показывает сайт)
photos/originals/   — исходные фото (не удалять, сайт их не загружает)
tools/optimize-photo.sh — сжатие нового фото в WebP
```

## Локальный просмотр

`products.json` загружается через `fetch`, поэтому просто открыть `index.html` двойным кликом нельзя —
нужен локальный сервер:

```bash
cd hasan-oil
python3 -m http.server 8080
# открыть http://localhost:8080
```

Проверить мобильную версию: в Chrome DevTools → Toggle device toolbar (Ctrl+Shift+M) → ширина 360.

## products.json

```jsonc
{
  "updated": "2026-10-01",          // дата обновления цен → «Цены актуальны на 1 октября 2026 г.»
  "categories": [ ... ],            // табы-фильтры, в этом порядке
  "products": [
    {
      "id": "walnut",               // уникальный латиницей, без пробелов; используется в ссылке #p-walnut
      "name": "Масло грецкого ореха",
      "brand": "HASAN oil",         // или null
      "category": "cold-pressed",   // id из списка categories
      "volumes": [
        { "size": "250 мл", "price": 1100 },   // цена числом, без пробелов и ₽
        { "size": "500 мл", "price": null }    // null → «цена по запросу»
      ],
      "short": "…",                 // одна фраза для карточки в каталоге
      // Разделы модального окна (любой можно не указывать — тогда раздел не выводится):
      "description": "…",           // «Описание». Перенос строки \n = новый абзац
      "composition": "…",           // «Чем ценно»
      "usage": "…",                 // «Как применять»
      "how_to_choose": "…",         // «Как выбрать»
      "storage": "…",               // «Хранение»
      "caution": "…",               // «С осторожностью» (бежевый блок)
      "country": null,              // страна производства или null (тогда строка не выводится)
      "photos": ["photos/walnut-1.webp"],      // первое фото — в карточке, все — в галерее модального окна; [] → заглушка
      "available": true,            // false → серая плашка «Нет в наличии», товар уходит в конец списка
      "featured": false             // true → бейдж «Хит»
    }
  ]
}
```

Если у объёма неизвестен размер (мыло, уксус) — `{ "size": null, "price": null }`, на сайте будет просто «Цена по запросу».

> JSON строгий: без комментариев, без запятой после последнего элемента, строки — в двойных кавычках.
> После правки проверьте файл: `python3 -m json.tool products.json > /dev/null && echo OK`
> или вставьте его на jsonlint.com.

### Изменить цену
1. Найдите товар в `products.json` (Ctrl+F по названию).
2. Поменяйте `"price"` у нужного объёма: `"price": 1200`. Цена неизвестна — `"price": null`.
3. Обновите дату `"updated"` в начале файла (формат `ГГГГ-ММ-ДД`).
4. Задеплойте (см. ниже).

### Добавить товар
1. Скопируйте блок любого похожего товара `{ ... },` и вставьте рядом (порядок в файле = порядок на сайте).
2. Задайте новый уникальный `id` и заполните поля.
3. Нет фото — оставьте `"photos": []`, сайт покажет фирменную заглушку с бутылкой и названием.

### Добавить фото
1. Положите исходник в `photos/originals/`.
2. Сожмите и сконвертируйте (нужен ImageMagick: `sudo apt install imagemagick` / `brew install imagemagick`):
   ```bash
   tools/optimize-photo.sh photos/originals/IMG_1234.jpg walnut-2
   ```
   Появятся `photos/walnut-2.webp` (1200 px, для модального окна) и `photos/walnut-2-sm.webp` (600 px, для карточки).
3. Пропишите в `products.json` путь **без** `-sm`: `"photos": ["photos/walnut-1.webp", "photos/walnut-2.webp"]`.
   Сайт сам возьмёт `-sm`-версию для карточки.

Без ImageMagick можно сконвертировать в [squoosh.app](https://squoosh.app) (WebP, качество ~75, ширина 1200 и 600)
и сохранить файлы с теми же именами. Карточки показывают фото в пропорции 4:5 — лучше вертикальные снимки,
товар по центру.

### Скрыть товар
- Временно нет в наличии: `"available": false` — товар остаётся на сайте с серой плашкой «Нет в наличии».
- Убрать совсем: удалите блок товара из `products.json` (не забудьте про запятые).

### Категории
Новая категория — добавьте `{ "id": "...", "name": "..." }` в `categories` и укажите её `id` у товаров.
Пустые категории в табах не показываются.

## Тексты

Исходник всех текстов сайта и товаров — `hasan-oil-texts.md`. При правке текста меняйте его и там, и в `products.json` / `index.html`.

Без медицинских обещаний: никаких «лечит», «лечебное», «понижает холестерин/давление/сахар»,
«укрепляет иммунитет» — даже если так написано на упаковке. Только продукт, способ производства, вкус,
применение в кулинарии и уходе. Для БАДов и капсул — фраза «Не является лекарственным средством» в поле `caution`.

## Контакты и тексты страницы

Правятся в `index.html`. Места, которые нужно уточнить у клиента, помечены комментарием `[УТОЧНИТЬ]`:
блок «Доставка и оплата», «О нас», адрес и ссылка на Telegram в подвале.
Номер WhatsApp и предзаполненный текст сообщения — в начале `script.js` (`WA_PHONE`, `WA_TEXT`).

## Превью ссылки (WhatsApp, Telegram)

Мессенджеры требуют **абсолютный** адрес картинки, поэтому в `index.html` в тегах `og:url` и `og:image`
прописан полный адрес `https://varsavvvuyy-stack.github.io/hasan-oil/`. Если сайт будет на другом
аккаунте или домене — замените его в этих двух тегах.
Картинка превью — `assets/og-image.jpg` (1200×630).

Telegram и WhatsApp кэшируют превью. Чтобы обновить в Telegram — отправьте ссылку боту
[@WebpageBot](https://t.me/WebpageBot). В WhatsApp можно добавить к ссылке `?v=2`.

## Публикация на GitHub Pages

Первый раз:
1. Создайте на GitHub репозиторий `hasan-oil` (публичный — для бесплатного Pages) и загрузите файлы в ветку `main`:
   ```bash
   git remote add origin https://github.com/<username>/hasan-oil.git
   git push -u origin main
   ```
2. На GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   Branch: `main`, папка `/ (root)` → **Save**.
3. Через 1–2 минуты сайт будет доступен по адресу `https://<username>.github.io/hasan-oil/`
   (ссылка появится там же, в Settings → Pages).
4. Проверьте превью: отправьте ссылку себе в WhatsApp/Telegram.

Каждое следующее обновление:
```bash
git add -A
git commit -m "Цены на 15.10"
git push
```
GitHub Pages пересоберёт сайт сам за 1–2 минуты (статус — во вкладке **Actions**).
Если старая версия «залипла» в браузере — обновите страницу с Ctrl+F5.

Можно править прямо в браузере: откройте `products.json` на GitHub → значок карандаша → внесите изменения →
**Commit changes**.

Файл `.nojekyll` в корне отключает обработку Jekyll — не удаляйте.
